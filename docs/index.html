Draft-day workspace

Manual first. Yahoo optional.

Refresh all sources persists public feeds and an independently refreshed read-only Yahoo snapshot. The prepared player board, scoring profile, roster settings, and rankings can still be exported as a checksummed package, and the live draft workflow does not depend on Yahoo remaining connected.

In-season workspace

Turn the league snapshot into a weekly plan.

Compare every roster, inspect starters and bench depth in a side drawer, review recent production and injuries, and see exactly which cached projection source supports each player. FantasyPros remains primary; ESPN only fills plausible gaps and is labeled wherever it appears.
